# FastExpress Frontend

Interfaz web del cotizador (HTML, CSS, JavaScript).

En el monorepo original se sirve desde el backend en `/app/`.
Con repos separados, abre `index.html` con un servidor estático o configura
el backend para apuntar a esta carpeta.

```bash
# Ejemplo con Python
python3 -m http.server 5500
# Luego http://127.0.0.1:5500
```
